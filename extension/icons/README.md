# Extension Icons

This directory should contain the following icon files:
- `icon16.png` - 16x16 pixels
- `icon32.png` - 32x32 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

These icons are referenced in the manifest.json file.

## Creating Icons

You can use any image editing tool to create these icons. The icons should represent the extension's functionality (e.g., a key, lock, or login symbol).

For testing purposes, you can use placeholder icons or generate them using online tools.
